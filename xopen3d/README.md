## Some feature for Luca Grasping Project

### Point Filter
- Given transformation of a point on table and camera, remove points outside and beside table (if given table height and width).

### ICP
- Given multiple full view point cloud of objects and source partial view of source point cloud, to find the most match one, and the match score.
- Distant point cloud icp of two point cloud, transformation, match score and visualization helper function.
